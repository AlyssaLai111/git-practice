## Article

[The Big Bang: A.I. Has Created a Code Overload - Mike Isaac and Erin Griffith](https://www.nytimes.com/2026/04/06/technology/ai-code-overload.html)

## Paragraph

I think it is common knowledge at this point to people in the field/learning about software development/engineering that A.I. is being pushed in several companies to increase efficiency in coding. Some companies have employees use A.I. to do the simplest of tasks so that they can spend more time on other issues, while others have been working with agentic A.I. where the A.I. is able to work somewhat independently from the worker. Overall, the things I've heard were generally vague since I don't actually have direct experience in this. Thus, I found this article by Mike Isaac and Erin Griffith to be interesting because it helps put into perspective the scale of the various effects of A.I. on work. For example, it was noted that there was a 10x increase in lines of code in one company. At face-value, this is quite amazing, but this effect of A.I. feels more absurd when the authors expand on the fact that this actually caused some issues where there is genuinely too much code being produced, so some companies feel they need to hire more senior engineers to be able to comb through it all. 

## Alisha Zaman's Comments 
Since A.I has been around for several years, in about a year or two, these senior engineers will be the junior engineers who have learned how to produce code with A.I or have relied on A.I continously. So, it makes me wonder if hiring more senior engineers will truly be able to solve the problem soon.
